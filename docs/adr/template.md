# NNNN：一句话描述决定

- 状态：Proposed
- 提议日期：YYYY-MM-DD
- 决策者／接受日期：待定
- 关联：issue／PR／源码／其他 ADR（没有则写“无”）
- 取代／被取代：无

## 背景

要解决什么问题？有哪些不能忽略的约束？只写影响选择的事实。

## 决定

明确选择什么、作用范围是什么，以及不包含什么。

## 备选方案

- 方案 A：主要优缺点，为什么没有选择。
- 方案 B：主要优缺点，为什么选择或没有选择。

## 后果与验证

- 收益：这个选择解决什么。
- 代价：接受什么限制、复杂度或迁移成本。
- 验证：用哪个测试、指标或评审确认约束成立。
- 重评条件：什么变化出现时需要另写 ADR 重新决策。
